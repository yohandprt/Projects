# CVRIE

## Préliminaires

```bash
source .venv/bin/activate # Entre dans l'environnement virtuel
pip install -r requirements.txt # installer les dépendances
```
```bash
deactivate # Sortir de l'environnement virtuel
```

## Lancement

>Ouvir le fichier `supervised_learning.ipynb` pour voir la classification supervisée
>Ouvir le fichier `unsupervised_learning.ipynb` pour voir la classification non-supervisée

## Fichiers importants

- `set_dataset` - *nettoie et met en forme les données des datasets*
- `supervised_learning.ipynb` - *contient l'apprentissage supervisé d'un modèle de machine learning sur des image de tumeur cérébrale*
- `unsupervised_learning.ipynb` - *contient l'apprentissage non-supervisé d'un modèle de machine learning sur des dialogues de patient*
